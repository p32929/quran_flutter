# Quran (quran_flutter)

A free Quran app with no ads and no account. Read the Quran with a translation you understand, even offline, listen to 42 reciters, and memorize ayat without replaying them by hand: the app repeats them for you. One codebase runs on Android, iPhone, Windows, macOS, Linux and the web.

**Try it in your browser:** https://p32929.github.io/quran_flutter/

**Downloads:** [latest release](https://github.com/p32929/quran_flutter/releases/latest)

## Features

1. **Read with translation.** Every surah ayah by ayah, with the translation right under each ayah.
2. **Works offline.** English, Bengali and Urdu translations come with the app, and you can download more.
3. **Listen to 42 reciters.** Play a whole surah or a single ayah.
4. **Memorize (hifz) with repeat.** Pick a range of ayat and the recitation repeats as many times as you need.
5. **Never lose your place.** Bookmark ayat and pick up where you left off.
6. **Search** by word in Bengali or English.
7. **Light and dark theme.**

## Run it yourself

You need [Flutter](https://flutter.dev) installed.

```bash
git clone https://github.com/p32929/quran_flutter.git
cd quran_flutter
flutter pub get
flutter run
```
