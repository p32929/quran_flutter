# quran_flutter

[WIP] A simple, clean Quran app built with Flutter — surah list, ayah-by-ayah reading with translation, audio recitation, bookmarks and search. Runs on Android, iOS, Windows, macOS, Linux and the web from one codebase.

**Try it in your browser:** https://p32929.github.io/quran_flutter/
**Downloads:** [latest release](https://github.com/p32929/quran_flutter/releases/latest)

## Features

- **Full surah list** and ayah-by-ayah surah view
- **Translations** alongside the Arabic
- **Audio recitation** playback
- **Search by word** in Bengali or English
- **Bookmark ayat** and pick up where you left off
- **Light / dark theme**

## Run it yourself

```bash
git clone https://github.com/p32929/quran_flutter.git
cd quran_flutter
flutter pub get
flutter run
```
